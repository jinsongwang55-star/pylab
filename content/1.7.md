## 本节目标

把前六节的知识组装成一个可用的小系统：带持久化的记账核心。

## 为什么用类

状态（记录集合）与操作（增、查、汇总）绑在一起。调用方不需要关心 JSON 存在哪、什么时候写盘。

```python
class Ledger:
    def __init__(self, path): ...
    def add(self, amount, desc, tag="其他"): ...
    def list(self, tag=None): ...
    def total(self): ...
```

## 设计要点

| 问题 | 方案 |
|---|---|
| ID 怎么生成 | 当前最大 ID + 1 |
| 金额怎么存 | `Decimal` 转字符串写入 JSON |
| 什么时候写盘 | 每次 `add` 之后立刻原子写 |
| 非法金额怎么办 | 抛 `ValueError`，不产生任何副作用 |
| 返回内部对象吗 | 返回副本，防止外部改坏内部状态 |

## 原子写

```python
tmp = self.path.with_name(self.path.name + ".tmp")
tmp.write_text(json.dumps(self.records, ensure_ascii=False, indent=2), encoding="utf-8")
os.replace(tmp, self.path)
```

`os.replace` 在同一文件系统内是原子操作：任何时刻磁盘上要么是旧的完整文件，要么是新的完整文件。

## 返回副本

```python
def list(self, tag=None):
    return [dict(r) for r in self.records if tag is None or r["tag"] == tag]
```

直接返回 `self.records` 会让调用方有能力破坏内部状态，这是封装泄漏。

## 练习

实现 `Ledger`：

- `__init__(path)`：读取已有 JSON；文件不存在则从空列表开始
- `add(amount, desc, tag="其他")`：校验金额，生成递增 ID，追加后写盘，返回新记录字典
- `list(tag=None)`：返回记录副本，可按 tag 过滤
- `total()`：返回所有记录的 `Decimal` 合计

金额规则与 1.1 一致：正数、有限、两位小数、四舍五入。

## 检查点

测试会：新建账本加三笔、重新实例化确认数据还在、按标签过滤、传入非法金额确认抛错且 **ID 未跳号**。
