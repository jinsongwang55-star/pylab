## 本节目标

掌握参数形式、LEGB 作用域、闭包，并永久记住可变默认参数这个坑。

## 参数的五种形式

```python
def f(a, b=2, *args, keyword_only, **kwargs):
    ...
```

| 形式 | 说明 |
|---|---|
| `a` | 位置参数，必填 |
| `b=2` | 默认参数，必须排在没有默认值的参数之后 |
| `*args` | 收集多余位置参数为 tuple |
| `keyword_only` | `*` 之后必须用关键字传参 |
| `**kwargs` | 收集多余关键字参数为 dict |

调用示例：`f(1, 2, 3, 4, keyword_only=5, extra=6)`。

## 可变默认参数陷阱

```python
def append_item(item, target=[]):     # 错误写法
    target.append(item)
    return target

append_item(1)    # [1]
append_item(2)    # [1, 2]   期望是 [2]
```

默认值在**函数定义时**求值一次，之后所有调用共享同一个列表对象。正确写法：

```python
def append_item(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target
```

## 作用域：LEGB

查找顺序：Local → Enclosing → Global → Built-in。

```python
count = 0

def outer():
    count = 10              # enclosing 层
    def inner():
        nonlocal count      # 声明要修改外层变量
        count += 1
        return count
    return inner
```

函数内只要出现赋值，该名字就是局部变量；想修改外层必须用 `nonlocal` 或 `global`。

## 闭包

内层函数记住外层函数的变量，即使外层已经返回：

```python
def make_counter(start=0):
    count = start
    def counter():
        nonlocal count
        value = count
        count += 1
        return value
    return counter
```

每次调用 `make_counter()` 都会创建一套独立的 `count`，互不影响。

## 练习

实现两个函数：

- `make_counter(start=0)`：返回一个函数，每次调用返回递增整数，从 `start` 开始；多个计数器互不干扰
- `append_item(item, target=None)`：把 `item` 追加到 `target` 并返回该列表；`target` 为 `None` 时新建列表，不能有跨调用的状态泄漏

## 检查点

测试会构造两个计数器交替调用。如果把 `count` 写成模块级变量，第二项就会失败。
