## 本节目标

理解对象什么时候被回收，掌握 `__slots__` 与弱引用这两个控制生命周期的工具。

## 引用计数

CPython 以引用计数为主、分代 GC 为辅：

```python
import sys

a = []
sys.getrefcount(a)   # 2（a 本身 + 传参临时引用）
b = a
sys.getrefcount(a)   # 3
del b
```

计数归零立即释放。循环引用（A 引用 B，B 又引用 A）靠 GC 定期清理。

## __slots__

默认每个实例都有一个 `__dict__`，灵活但占内存。字段固定的类可以声明槽位：

```python
class Point:
    __slots__ = ("x", "y")

    def __init__(self, x, y):
        self.x = x
        self.y = y
```

代价与限制：

- 不能再动态添加属性
- 不能多继承带非空 `__slots__` 的类
- 实例默认不支持弱引用（需要把 `"__weakref__"` 加进槽位）

十万个小对象时，内存差距非常明显。

## 弱引用

弱引用不增加引用计数，对象可以被正常回收：

```python
import weakref

class Node:
    pass

node = Node()
ref = weakref.ref(node)
ref()            # <Node>
del node
ref()            # None
```

缓存、观察者列表、父子互指的场景用弱引用，避免让缓存本身变成内存泄漏。

`WeakValueDictionary` 是现成实现：值被回收后键自动消失。

```python
import weakref

cache = weakref.WeakValueDictionary()
cache["a"] = obj
del obj          # 没有其他强引用后，cache 里自动没有 "a"
```

## 常见泄漏

| 泄漏源 | 处理 |
|---|---|
| 全局缓存无限增长 | 加容量上限或 TTL |
| 缓存强引用对象 | 改 `WeakValueDictionary` |
| 闭包持有大对象 | 及时解除引用 |
| 循环引用 + `__del__` | 避免在 `__del__` 里做复杂逻辑 |

## 练习

实现：

- `Point`：`__slots__ = ("x", "y")`，构造时赋值
- `WeakCache`：基于 `weakref.WeakValueDictionary` 的 `put` / `get` / `__len__`

## 检查点

测试会验证 Point 没有 `__dict__`、不能新增属性；WeakCache 在对象只剩弱引用后长度归零。
