## 本节目标

把数据结构和函数契约写进代码，让编辑器和静态检查器在运行前发现问题。

## 标注是契约，不是装饰

```python
def total(prices: list[int]) -> int:
    return sum(prices)
```

标注在运行时**不强制**，但有三个实际作用：

- 编辑器补全与跳转
- mypy / pyright 静态检查
- 给读代码的人一个不用猜的契约

## 常用写法

| 写法 | 含义 |
|---|---|
| `list[str]` | 字符串列表 |
| `dict[str, int]` | 键 str、值 int |
| `tuple[int, ...]` | 任意长度整数元组 |
| `int | None` | 整数或 None |
| `Callable[[int], str]` | 接收 int、返回 str 的函数 |

Python 3.9+ 直接用内置泛型 `list[str]`，不要再用 `typing.List`。

## TypedDict：给字典定结构

字典的键名拼错是最常见的低级 bug。`TypedDict` 把键和值类型写死：

```python
from typing import TypedDict

class User(TypedDict):
    name: str
    age: int

def adult_names(users: list[User]) -> list[str]:
    return [u["name"] for u in users if u["age"] >= 18]
```

运行时它仍然是普通 dict，但类型检查器会拒绝 `u["nmae"]`。这是在不引入类的开销下约束字典的最佳方式。

## 泛型函数

```python
from typing import TypeVar

T = TypeVar("T")

def first(items: list[T]) -> T | None:
    return items[0] if items else None
```

`first([1, 2])` 推出 `int | None`，`first(["a"])` 推出 `str | None`。

## 什么时候值得标注

- 公共函数、跨模块调用：必须标
- 数据结构：必须标
- 五行以内的私有辅助函数：可以省
- 不要为标注堆 `cast` 和 `Any`，那只是把问题藏起来

## 练习

- 定义 `User(TypedDict)`，包含 `name: str` 与 `age: int`
- 实现 `adult_names(users: list[User]) -> list[str]`，返回 `age >= 18` 的 name，保持原顺序

## 检查点

测试会用 `typing.get_type_hints` 读取你的标注，**标注写错也会失败**，不只看运行结果。
