## 本节目标

用 `dataclass` 表达数据，用 `frozen=True` 保证不可变，用 `__post_init__` 做入口校验。

## 为什么不用 dict

```python
order = {"price": "35.5", "qty": 2}
order["prie"]     # 拼错不报错，得到 KeyError 或更糟的默认值
```

字典没有结构，键名靠记忆。`dataclass` 自动生成 `__init__`、`__repr__`、`__eq__`：

```python
from dataclasses import dataclass
from decimal import Decimal

@dataclass
class Item:
    name: str
    price: Decimal

Item("咖啡", Decimal("18.0")) == Item("咖啡", Decimal("18.0"))   # True
print(Item("咖啡", Decimal("18.0")))                              # 可读的输出
```

## frozen：不可变

```python
@dataclass(frozen=True)
class Item:
    name: str
    price: Decimal

item = Item("咖啡", Decimal("18"))
item.price = Decimal("20")     # FrozenInstanceError
```

不可变对象可以安全地作为字典键、在多个函数间共享、被缓存。**数据一旦创建就不该被就地修改**，这条在并发和调试时能省下大量时间。

## __post_init__：入口校验

```python
@dataclass(frozen=True)
class Item:
    name: str
    price: Decimal
    tags: tuple[str, ...] = ()

    def __post_init__(self) -> None:
        if not self.name.strip():
            raise ValueError("name 不能为空")
        if self.price <= 0:
            raise ValueError("price 必须大于 0")
```

校验放在构造入口，非法对象从一开始就不存在，后续代码不用再防御。

注意 `frozen=True` 时不能在 `__post_init__` 里直接赋值。真需要规范化时用：

```python
object.__setattr__(self, "name", self.name.strip())
```

## 可变默认值的坑

```python
@dataclass
class Bad:
    tags: list[str] = []          # ValueError: mutable default

@dataclass
class Good:
    tags: list[str] = field(default_factory=list)
```

`dataclass` 会直接拒绝可变默认值，这比普通函数参数安全。用不可变容器更彻底：`tags: tuple[str, ...] = ()`。

## dataclass vs NamedTuple

| 特性 | dataclass | NamedTuple |
|---|---|---|
| 可变 | 可配置 | 永远不可变 |
| 校验 | `__post_init__` | 无钩子 |
| 解包 | 不支持 | 支持 |
| 适用 | 领域对象 | 轻量值对象 |

## 练习

实现 `Item`：

- `frozen=True`
- 字段：`name: str`、`price: Decimal`、`tags: tuple[str, ...] = ()`
- `__post_init__` 校验：`name.strip()` 为空抛 `ValueError`，`price <= 0` 抛 `ValueError`

## 检查点

测试会验证：赋值被拒绝、值相等、默认 tags 为空元组、非法输入抛 `ValueError`。
