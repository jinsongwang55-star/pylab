## 本节目标

把 pathlib、异常处理、文件操作拼成一个真正能用的工具，并且保证它可以撤销。

## 功能拆解

```bash
python filesorter.py organize --path ~/Downloads --dry-run
python filesorter.py organize --path ~/Downloads
python filesorter.py undo --path ~/Downloads
```

本练习只要求两个纯函数；命令行外壳在 2.3 已经练过，拼起来就是完整工具。

## organize 的决策点

| 问题 | 方案 |
|---|---|
| 扫描范围 | 只处理直接子文件，避免把已分类目录反复嵌套 |
| 跳过什么 | 隐藏文件、符号链接、目录 |
| 重名怎么办 | `photo.jpg` 已存在 → `photo(1).jpg`，循环探测到不冲突 |
| 预演怎么保证不写盘 | dry_run 只计算目标路径，不建目录、不移动 |
| 返回什么 | `[{"src": ..., "dst": ...}]`，绝对路径，供 undo 使用 |

## 重名探测

```python
def unique_path(target):
    if not target.exists():
        return target
    counter = 1
    while True:
        candidate = target.with_name(f"{target.stem}({counter}){target.suffix}")
        if not candidate.exists():
            return candidate
        counter += 1
```

不要用 `try: shutil.move(...) except FileExistsError` —— 异常不该拿来当控制流。

## undo 为什么必须倒序

整理过程中可能产生链式改名。倒序回滚才能保证每一步的原位置已经空出来。

原位置已被占用时必须跳过，绝不能覆盖。

## 练习

实现两个函数：

- `organize(directory, dry_run=False) -> list[dict]`
- `undo(moves) -> int`

分类规则沿用 2.0 的表。返回的列表按 `dst` 路径排序，保证结果可预测。

## 检查点

测试覆盖：移动结果、dry_run 零改动、重名不覆盖、undo 完整恢复、原位置被占用时跳过并返回正确数量。
