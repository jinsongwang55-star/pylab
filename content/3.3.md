## 工程化的四个支柱

| 支柱 | 工具 | 解决的问题 |
|---|---|---|
| 项目声明 | pyproject.toml | 依赖、入口、工具配置集中一处 |
| 测试 | pytest | 改完代码几秒内知道有没有坏 |
| 风格与静态检查 | ruff | 消灭低价值争论，提前发现未使用变量等问题 |
| 持续集成 | GitHub Actions | 每次 push 自动跑，不依赖人的自觉 |

## pyproject.toml

```toml
[project]
name = "filesorter"
version = "0.1.0"
requires-python = ">=3.10"
dependencies = []

[project.optional-dependencies]
dev = ["pytest>=8", "ruff>=0.6"]

[project.scripts]
filesorter = "filesorter.cli:main"

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[tool.pytest.ini_options]
testpaths = ["tests"]
addopts = "-q"

[tool.ruff]
line-length = 100
target-version = "py310"

[tool.ruff.lint]
select = ["E", "F", "I", "UP", "B"]
```

推荐 src 布局：

```
filesorter/
├── pyproject.toml
├── src/
│   └── filesorter/
│       ├── __init__.py
│       ├── cli.py
│       └── core.py
└── tests/
    ├── test_core.py
    └── test_cli.py
```

src 布局强制「安装后才能导入」，能提前暴露打包遗漏。

## pytest

```python
# tests/test_core.py
from pathlib import Path

import pytest

from filesorter.core import classify


def test_classify_python_file(tmp_path: Path):
    (tmp_path / "a.py").write_text("")
    assert classify(tmp_path) == {"code": ["a.py"]}


@pytest.mark.parametrize("name,expected", [
    ("a.jpg", "images"),
    ("a.unknownext", "others"),
])
def test_categories(name, expected, tmp_path):
    (tmp_path / name).write_text("")
    assert list(classify(tmp_path)) == [expected]
```

关键点：

- 文件名 `test_*.py`，函数名 `test_*`
- 直接用 `assert`，不需要记 `assertEqual`
- `tmp_path` 是内置 fixture，每个测试自动获得独立临时目录
- `@pytest.mark.parametrize` 一组代码覆盖多组输入
- 自定义 fixture 用 `@pytest.fixture`，测试函数按参数名取用

常用命令：

```bash
pytest                 # 全部
pytest -q              # 简洁输出
pytest -k classify     # 只跑名字含 classify 的
pytest --lf            # 只跑上次失败的
```

## ruff

```bash
ruff check .           # 检查
ruff check --fix .     # 自动修能修的
ruff format .          # 格式化（替代 black + isort）
```

规则选择：`E`（pycodestyle 错误）、`F`（pyflakes，真 bug）、`I`（import 排序）、`UP`（旧语法升级）、`B`（bugbear，常见陷阱）。

## 持续集成

`.github/workflows/ci.yml`：

```yaml
name: CI

on:
  push:
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -e ".[dev]"
      - run: ruff check .
      - run: ruff format --check .
      - run: pytest
```

提交前本地先跑一遍，CI 只是最后一道保险。
