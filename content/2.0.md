## 本节目标

把路径当对象处理，不再用字符串拼接。`pathlib` 是 Python 3 之后操作文件系统的标准方式，`os.path` 只在维护老代码时使用。

## Path 对象

```python
from pathlib import Path

root = Path.home() / "Downloads"      # / 运算符拼接，自动处理分隔符
print(root)                           # Windows 上会转成反斜杠
print(root.name)                      # Downloads
print(root.parent)                    # /home/you
```

| 属性 | 结果（以 /data/report.tar.gz 为例） |
|---|---|
| `.name` | report.tar.gz |
| `.stem` | report.tar |
| `.suffix` | .gz |
| `.suffixes` | ['.tar', '.gz'] |
| `.parent` | /data |

`.suffix` 只取最后一段，复合扩展名要自己处理。

## 判断与遍历

```python
p = Path("data")

p.exists()
p.is_file()        # 路径不存在时返回 False，不会报错
p.is_dir()
p.is_symlink()

for child in p.iterdir():     # 直接子项，不递归
    print(child.name)

for py in p.rglob("*.py"):    # 递归匹配
    print(py)
```

`iterdir()` 返回所有直接子项，包含目录和隐藏文件，需要自己过滤。

`glob("*.py")` 在 Linux 上大小写敏感，`.PY` 不会匹配。做扩展名分类时统一用 `path.suffix.lower()` 自己判断，不要依赖通配符。

## 读写

```python
text = Path("a.txt").read_text(encoding="utf-8")
Path("b.txt").write_text("内容", encoding="utf-8")
```

**永远显式写 `encoding="utf-8"`**。省略时用系统默认编码，换台机器就可能乱码。

## 练习

实现 `classify_files(directory)`：

- 只扫描直接子文件，不递归
- 跳过目录、符号链接、隐藏文件（名字以 `.` 开头）
- 扩展名转小写后按下表归类，没有扩展名归入 `others`
- 只返回非空类别，键顺序固定为 images → documents → code → archives → others
- 每个类别内的文件名升序排列

| 类别 | 扩展名 |
|---|---|
| images | .jpg .jpeg .png .gif .webp .svg |
| documents | .pdf .doc .docx .txt .md .csv |
| code | .py .js .ts .html .css .json |
| archives | .zip .tar .gz .bz2 .7z |

测试会构造隐藏文件、子目录、符号链接和大写扩展名。`iterdir()` + `is_file()` + `suffix.lower()` 就够了。
