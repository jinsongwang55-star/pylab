## 本节目标

把前几节的路由、校验、鉴权接到真实框架上，跑通一个可访问的 API。本节没有判题。

## 安装

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install fastapi "uvicorn[standard]"
```

## 最小应用

```python
# main.py
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI(title="Mini Blog")

class PostIn(BaseModel):
    title: str = Field(min_length=1, max_length=100)
    content: str = Field(min_length=1)

POSTS: list[dict] = []

@app.get("/posts")
def list_posts():
    return {"items": POSTS}

@app.post("/posts", status_code=201)
def create_post(post: PostIn):
    record = {"id": len(POSTS) + 1, **post.model_dump()}
    POSTS.append(record)
    return record
```

运行：

```bash
uvicorn main:app --reload
```

打开 `http://127.0.0.1:8000/docs`，你会看到自动生成的交互文档，可以直接发请求。这不是插件，是 FastAPI 根据类型标注生成的。

## 路径参数与校验

```python
@app.get("/posts/{post_id}")
def get_post(post_id: int):
    ...
```

声明 `int` 后，FastAPI 自动转换类型，失败时返回 422。5.0 手写的路由与 5.1 的校验，框架在这里替你做了。

## 依赖注入做鉴权

```python
from fastapi import Depends, Header, HTTPException

def current_user(authorization: str | None = Header(default=None)) -> int:
    if not authorization or not authorization.startswith("Bearer "):
        raise HTTPException(status_code=401, detail="未登录")
    user_id = verify_token(authorization[7:])
    if user_id is None:
        raise HTTPException(status_code=401, detail="令牌无效或已过期")
    return user_id

@app.post("/posts", status_code=201)
def create_post(post: PostIn, user_id: int = Depends(current_user)):
    ...
```

`Depends` 就是依赖注入：框架负责调用 `current_user`，你只声明需要它的结果。5.2 的 `verify_token` 可以直接接进来。

## 数据库

开发期先用内存字典，需要持久化就换 SQLite：

```python
import sqlite3

def get_db():
    conn = sqlite3.connect("blog.db")
    conn.row_factory = sqlite3.Row
    try:
        yield conn
    finally:
        conn.close()

@app.get("/posts")
def list_posts(db=Depends(get_db)):
    rows = db.execute("SELECT id, title FROM posts ORDER BY id DESC").fetchall()
    return {"items": [dict(row) for row in rows]}
```

规模再大再引入 SQLAlchemy 2.0（异步 session + Alembic 迁移）。不要一上来就上 ORM。

## 分层

```
src/blog/
├── main.py          # 应用装配、路由
├── schemas.py       # Pydantic 模型
├── service.py       # 业务逻辑，纯函数优先
├── repository.py    # 数据库读写
└── security.py      # 哈希与令牌
```

路由函数尽量薄：解析参数 → 调 service → 返回。业务逻辑不依赖 FastAPI，才能单独测。

## CORS

前后端分开部署时才需要：

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],
    allow_methods=["*"],
    allow_headers=["*"],
)
```

`allow_origins=["*"]` 不要带到生产。

```python
from fastapi.testclient import TestClient
from main import app

client = TestClient(app)

def test_create_and_list():
    created = client.post("/posts", json={"title": "t", "content": "c"})
    assert created.status_code == 201
    assert client.get("/posts").json()["items"]
```
