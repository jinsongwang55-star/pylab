## 本节目标

用标准库实现密码哈希与签名令牌，理解 JWT 的骨架和常见错误。

## 绝不能存明文

数据库泄露时，明文密码等于全部账号失守。也不要自己发明加密算法，用成熟的 KDF：

- PBKDF2（`hashlib.pbkdf2_hmac`，标准库自带）
- bcrypt / scrypt / Argon2（第三方，生产更推荐）

## 加盐

同一个密码，不同用户必须得到不同哈希，否则攻击者可以用彩虹表批量破解。

```python
import os
import hashlib

salt = os.urandom(16)
digest = hashlib.pbkdf2_hmac("sha256", password.encode(), salt, 260_000)
```

盐不需要保密，和哈希一起存：

```
pbkdf2_sha256$260000$<salt_hex>$<hash_hex>
```

## 比较要用常数时间

```python
hmac.compare_digest(a, b)   # 正确
a == b                       # 错误，存在时序攻击面
```

## 令牌不是加密，是签名

JWT 由三段组成：`header.payload.signature`。payload 只是 Base64，**任何人都能解码看到内容**，它只保证「没被篡改」。

本节实现一个简化版：

```
<user_id>.<expires_at>.<hmac_sha256_signature>
```

签名覆盖前两段，验证时重算并比较；同时检查过期时间。

## 常见错误

| 错误 | 后果 |
|---|---|
| 把密码放进 token payload | 等于明文泄露 |
| 不校验过期时间 | 令牌永久有效 |
| 用 `==` 比较签名 | 时序攻击面 |
| 密钥写死在代码里 | 泄露即全部伪造 |

## 练习

实现四个函数（签名见起始代码）：

- `hash_password(password, *, salt=None)`：返回上述格式，salt 为 None 时随机生成
- `verify_password(password, stored)`：格式非法或密码错误都返回 False
- `make_token(user_id, secret, ttl=3600, now=None)`：生成 `id.expires.signature`
- `verify_token(token, secret, now=None)`：签名错误、格式错误、已过期都返回 None，否则返回 user_id

## 检查点

测试用固定 salt 与固定 now，验证格式、错误密码、篡改令牌、过期边界（`now == expires` 视为过期）。
