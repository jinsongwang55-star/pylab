## 本节目标

理解「函数是一等对象」，能手写带 `functools.wraps` 的装饰器。

## 函数是对象

```python
def greet(name):
    return f"hi {name}"

say = greet          # 不加括号，绑定的是函数对象
print(say("A"))      # hi A
```

既然函数是对象，就能作为参数传入、作为返回值传出。装饰器就是「接收函数、返回新函数」的函数。

## 手工展开

```python
def log_calls(func):
    def wrapper(*args, **kwargs):
        print(f"[call] {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

def add(a, b):
    return a + b

add = log_calls(add)     # 这就是装饰器
```

`@` 语法只是语法糖，下面两段等价：

```python
@log_calls
def add(a, b):
    return a + b
```

```python
def add(a, b):
    return a + b
add = log_calls(add)
```

## 为什么必须用 wraps

不加 `@wraps(func)`，`add.__name__` 会变成 `wrapper`，`add.__doc__` 会丢失。调试、日志、框架注册都会因此出错。

```python
from functools import wraps

def log_calls(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"[call] {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

## 带参数的装饰器

多包一层函数：

```python
def retry(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                try:
                    return func(*args, **kwargs)
                except Exception:
                    pass
            raise RuntimeError("重试次数用尽")
        return wrapper
    return decorator

@retry(3)
def flaky():
    ...
```

## 练习

实现 `log_calls(func)`：

- 调用前向 `stdout` 打印一行 `[call] 函数名`
- 原样返回被装饰函数的返回值
- 保留原函数的 `__name__` 与 `__doc__`
