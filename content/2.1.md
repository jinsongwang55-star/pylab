## 本节目标

用 `re` 从非结构化文本里稳定取数，而不是靠 `split` 和切片硬凑。

## 基本函数

| 函数 | 作用 | 返回 |
|---|---|---|
| `re.search(pattern, text)` | 找第一个匹配 | Match 或 None |
| `re.match` | 只从字符串开头匹配 | Match 或 None |
| `re.fullmatch` | 整串必须完全匹配 | Match 或 None |
| `re.findall` | 找出所有匹配 | list |
| `re.sub` | 替换所有匹配 | 新字符串 |

```python
import re

text = "订单 A-1024 金额 99.50"
m = re.search(r"A-(\d+)", text)
m.group(0)     # 'A-1024'，整个匹配
m.group(1)     # '1024'，第一个分组

re.findall(r"\d+", text)       # ['1024', '99', '50']
re.sub(r"\d+", "#", text)      # '订单 A-# 金额 #.#'
```

## 原始字符串

写正则一律用 `r"..."`。不加 `r`，反斜杠会先被 Python 字符串处理一遍，`\d` 可能变成普通字符，规则直接失效。

## 分组与反向引用

```python
re.sub(r"(\d{3})\d{4}(\d{4})", r"\1****\2", "13812348000")
# '138****8000'
```

替换串里的 `\1`、`\2` 引用分组，这是脱敏、重排格式的标准手法。

## 边界

`\d{11}` 会从更长的数字串中间截出一段，所以要加边界：

```python
r"(?<!\d)1\d{10}(?!\d)"
```

- `(?<!\d)`：前面不能是数字
- `(?!\d)`：后面不能是数字

## 贪婪与非贪婪

```python
re.search(r"<(.+)>", "<a><b>").group(1)     # 'a><b'，贪婪
re.search(r"<(.+?)>", "<a><b>").group(1)    # 'a'，非贪婪
```

默认贪婪，加 `?` 变非贪婪。
