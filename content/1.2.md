## 本节目标

按场景选对容器，会用推导式与 `collections` 里的工具。

## 四种内置容器

| 容器 | 有序 | 可变 | 可重复 | 查找 | 典型用途 |
|---|---|---|---|---|---|
| list | 是 | 是 | 是 | O(n) | 有序序列 |
| tuple | 是 | 否 | 是 | O(n) | 不可变记录、字典键 |
| dict | 插入序 | 是 | 键唯一 | O(1) | 键值映射 |
| set | 否 | 是 | 否 | O(1) | 去重、集合运算 |

选择顺序：键值映射用 dict，去重用 set，需要顺序用 list，需要不可变用 tuple。

## 常用操作

```python
records = [{"tag": "餐饮", "amount": "35.5"}, {"tag": "交通", "amount": "12"}]

for index, record in enumerate(records, start=1):
    print(index, record["tag"])

names = ["a", "b"]
scores = [90, 85]
print(list(zip(names, scores)))     # [('a', 90), ('b', 85)]

print(records[0])     # 第一个
print(records[-1])    # 最后一个
print(records[1:])    # 切片，返回新列表，原列表不变
```

## 推导式

```python
from decimal import Decimal

amounts = [Decimal(r["amount"]) for r in records]                   # 列表推导式
lookup = {r["tag"]: r["amount"] for r in records}                   # 字典推导式
unique_tags = {r["tag"] for r in records}                           # 集合推导式
total = sum((Decimal(r["amount"]) for r in records), Decimal("0"))  # 生成器表达式
```

生成器表达式用圆括号，惰性求值，不占一整块内存。数据量大时用它替代列表推导式。

## collections

```python
from collections import Counter, defaultdict
from decimal import Decimal

Counter(["a", "b", "a"]).most_common()      # [('a', 2), ('b', 1)]

totals = defaultdict(Decimal)
for r in records:
    totals[r["tag"]] += Decimal(r["amount"])
```

`defaultdict(Decimal)` 在键不存在时自动调用 `Decimal()` 得到 0，省掉手写判空。

## 排序

```python
sorted(records, key=lambda r: Decimal(r["amount"]), reverse=True)
```

`key` 返回排序依据。多关键字时返回元组，例如先按标签升序、再按金额降序：

```python
key=lambda r: (r["tag"], -Decimal(r["amount"]))
```

## 练习

实现 `summarize_tags(records)`：

- 输入形如 `[{"amount": "35.5", "tag": "餐饮"}, ...]`
- 返回 `{tag: 合计}`，值是 `Decimal`
- 按合计**降序**排列；合计相同时按 tag 字典序**升序**
- 空列表返回 `{}`

## 检查点

两个易错点：金额必须用 `Decimal(r["amount"])` 而不是 `float`；返回顺序会被严格断言，普通 dict 在 Python 3.7+ 保留插入序，所以构造时就要按目标顺序写入。
