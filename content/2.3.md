## 本节目标

为脚本造一个像样的命令行接口：子命令、必填参数、布尔开关、类型转换。

## 最小结构

```python
import argparse

parser = argparse.ArgumentParser(prog="tool", description="示例工具")
parser.add_argument("source", help="位置参数，必填")
parser.add_argument("--output", default="out.txt")
parser.add_argument("--force", action="store_true")
args = parser.parse_args()
```

`parse_args()` 返回 Namespace，用 `args.source`、`args.force` 访问。解析失败时它打印用法并抛 `SystemExit`，不会返回。

## 类型转换

```python
from pathlib import Path

parser.add_argument("--path", type=Path, required=True)
```

`type=Path` 直接把字符串转成 Path 对象。也可以用 `type=int` 或自定义函数。

## 子命令

```python
sub = parser.add_subparsers(dest="command", required=True)

p_add = sub.add_parser("add", help="新增")
p_add.add_argument("--title", required=True)
p_add.set_defaults(func=do_add)

p_list = sub.add_parser("list", help="列出")
p_list.set_defaults(func=do_list)
```

`required=True` 让「不写子命令」直接报错，而不是静默什么都不做。

调用 `args.func(args)` 分发。

## 常见错误

| 写法 | 问题 |
|---|---|
| `add_argument("--path")` 不加 required | 得到 None，后面崩在无关位置 |
| 子命令忘记 `required=True` | 空跑不报错，最难排查 |
| 解析后再手动校验类型 | 应该在 `type=` 里一次做完 |

## 练习

实现 `build_parser()`，返回配置好的 `ArgumentParser`：

- `prog = "filesorter"`
- 子命令 `organize`：`--path`（必填，`Path` 类型）、`--dry-run`（`store_true`，默认 False）
- 子命令 `undo`：`--path`（必填，`Path` 类型）
- 不提供子命令时应当报错

## 检查点

测试会检查 `args.path` 是 Path 而不是字符串、`dry_run` 默认为 False、以及缺少参数或子命令时是否抛 `SystemExit`。
